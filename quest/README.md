# 행운의 궁전 (Palace of Fortune)

9가지 미니게임이 12개 에피소드(총 283스테이지)의 이야기로 이어지는 퍼즐 어드벤처입니다. 그 뒤로는 시즌이 끝없이 이어집니다.
플레이어가 고르지 않아도 다음 스테이지가 저절로 시작됩니다.

- 주소(GitHub Pages): `https://swxd456-spec.github.io/-/quest/`
- 슬롯머신 단독 게임(`/` 폴더)과는 완전히 분리되어 있습니다.

## 1. 기획

### 스토리 — 「별시계와 열두 개의 세계」
궁전의 슬롯머신은 하나하나가 다른 세계로 이어지는 문입니다. 세계들의 행운은 궁전의 **별시계**로 모입니다.
그런데 그림자 마술사 **녹턴**이 별시계의 별조각 12개를 뜯어 갔고, 자정이 되면 모든 행운이 사라집니다.
견습 수호자 여우 **루미**가 12개의 세계(시계의 한 시간마다 하나)를 돌며 친구를 사귀고, 그림자 보스에게서 별조각을 되찾습니다.
중반에는 반전이 있습니다. 녹턴은 사실 진짜 도둑인 **탐욕의 거울**에게서 별조각을 숨기고 있었습니다. 12화를 마치면 「새벽의 궁전」 시즌이 시작되고, 같은 세계들을 더 어렵게 다시 돕니다(끝없이 반복).

| 에피소드 | 세계 | 새 친구 | 스테이지 | 처음 나오는 게임 |
|---|---|---|---|---|
| 1 | 네온 시티의 밤 | — | 15 | 팡팡·탑쌓기·사천성·틀린그림 |
| 2 | 녹아내린 캔디 왕국 | 토토(토끼 제과사) | 18 | 버블 팡팡 |
| 3 | 가라앉은 산호 바다 | 핑구 선장(펭귄) | 20 | 벽돌깨기 |

- 에피소드마다 시작·끝 컷신이 있습니다(캐릭터 등장 연출, 대사, 번개·플래시 효과, 별시계 타이틀 카드).
- 5번째 스테이지마다 **슬롯 축제**, 마지막 스테이지는 **보스전**입니다.
- 지도(앵그리버드 방식): 구불구불한 길 위에 스테이지가 있고, 루미가 다음 칸으로 뛰어갑니다. 3초 뒤 자동으로 시작합니다. 지난 스테이지는 눌러서 별 3개에 다시 도전할 수 있습니다.

### 게임 9종
| 게임 | 방식 |
|---|---|
| 팡팡 프렌즈 | 애니팡식 매치3, 60초 점수 도전, 특수 블록·콤보·FEVER |
| 버블 팡팡 | 버블 슈터, 갇힌 친구 구출 |
| 보석 벽돌깨기 | 아르카노이드식, 아이템 7종 |
| 보석 블록 | 1010!/블록블라스트식, 줄 지우기 + 보석 모으기 |
| 슈팅 스타 새총 | 앵그리버드식 물리 새총, 특수 새 3종 |
| 하늘 궁전 쌓기 | 타이밍 탑 쌓기, 퍼펙트 연속 |
| 사천성 · 틀린그림찾기 | 1차 버전 그대로 |
| 행운 축제 | 슬롯머신 30종 |

- **난이도:** 각 게임은 "그 게임을 몇 번째로 하는지"에 따라 아주 천천히 어려워집니다. 1~3판은 튜토리얼 수준이고, 수십 판에 걸쳐 오른 뒤 완만해집니다. 모든 곡선은 config.txt에서 조절할 수 있습니다.
- **처음 나오는 게임**은 시작 전에 방법 카드가 나옵니다.

### 경쟁
- **주간 리그:** 스테이지를 깰 때마다 리그 포인트가 쌓이고, 궁전 주민 라이벌 19명과 순위를 다툽니다. 매주 월요일에 정산합니다(5위까지 승급, 17위부터 강등, 순위 보상). 브론즈부터 레전드까지 7단계입니다. 라이벌은 게임 속 캐릭터입니다(서버가 없어서 실제 사람 순위는 아닙니다).
- **친구 도전장(실제 사람과 대결):** 결과 화면의 「⚔️ 친구에게 도전장」을 누르면 같은 판(같은 그림·같은 난이도)의 링크가 만들어집니다. 카톡 등으로 보내면, 친구가 링크를 열어 같은 판을 하고 점수를 비교합니다. 이기면 보상을 받고 다시 도전장을 보낼 수 있습니다.

### 퀘스트
- 일일 퀘스트 3개(게임별 클리어, 별 모으기, 리그 포인트 등)
- 업적 12종(단계가 끝없이 올라감)
- 7일 출석, 레벨업 보상, 에피소드 보상

## 2. 운영자 설정 — `config.txt`

**`quest/config.txt` 하나로 모든 수치를 조절합니다.**
GitHub에서 파일을 열고 연필(✏️)을 눌러 숫자를 바꾼 뒤 *Commit changes*를 누르세요.
1~2분 뒤 페이지에 반영되고, 이미 켜져 있는 게임도 1분마다(또는 앱으로 돌아올 때) 새 값을 읽습니다.

| 섹션 | 조절하는 것 |
|---|---|
| `[경제]` | 시작 코인 |
| `[캠페인]` | 자동 시작·자동 진행 시간, 슬롯 축제 스핀 수, 별3개·보스·에피소드·도전장 보상 |
| `[팡팡프렌즈]` `[버블팡팡]` `[벽돌깨기]` `[보석블록]` `[새총]` `[탑쌓기]` | 새 게임 6종의 입장료·보상·도구 가격·난이도 곡선(키마다 한국어 설명) |
| `[사천성]` | 입장료, 보상, 힌트·셔플·시간연장 가격, 보드 크기 단계, 제한시간 곡선, 그림 종류 수, 특수타일 확률, 중력 모드 |
| `[틀린그림]` | 입장료, 보상, 오답 감점, 차이 개수 곡선, 제한시간 곡선, 미묘함(0~100), 물건 수 |
| `[슬롯 RTP]` | **`전체 = 96` 하나만 바꾸면 30개 머신이 한꺼번에 바뀝니다.** 머신별로 다르게 하려면 그 줄 앞의 `# `를 지우세요. |
| `[상점]` | `결제모드 = 테스트` 또는 `구글플레이`, 상품 목록(코인 \| 표시가격 \| 상품ID) |
| `[보상]` | 출석, 일일 퀘스트, 홀 개방, 업적 보상 |

- 난이도는 '판 번호'에 따라 올라갑니다. 예를 들어 `제한시간_시작 = 200`, `제한시간_감소 = 3`, `제한시간_최소 = 100`이면 1판은 200초, 2판은 197초로 줄다가 100초 밑으로는 내려가지 않습니다.
- RTP는 슬롯 화면의 ⓘ(배당표)에 그대로 공개됩니다.

## 3. 결제

- `결제모드 = 테스트`: 실제 돈이 오가지 않습니다. 확인 창에서 '지급하기'를 누르면 바로 코인이 들어옵니다. 개발과 시연용입니다.
- `결제모드 = 구글플레이`: 플레이스토어에서 설치한 앱(TWA) 안에서 **Google Play 결제**(Digital Goods API)로 구매합니다. 가격은 Play Console에 등록한 현지 가격으로 표시됩니다.
  1. Play Console → 수익 창출 → 인앱 상품에서 `coins_5000` 같은 ID로 **소비성 상품**을 만듭니다. ID는 config.txt의 상품 ID와 같아야 합니다.
  2. PWABuilder로 APK/AAB를 만들 때 **Play Billing** 옵션을 켭니다.
  3. ⚠️ 실서비스 전에는 구매 토큰을 **서버에서 검증**해야 합니다(Google Play Developer API). 지금은 기기에서만 처리하므로 조작에 약합니다. 해당 위치는 `js/shop.js`에 TODO로 표시해 두었습니다.
- 코인은 게임 안에서만 쓰는 가상 재화이며 **현금으로 바꿀 수 없습니다.**

## 4. 틀린그림 사용자 이미지 (예: 150장)

1. 원본과 바뀐 그림을 한 쌍씩 `quest/img/`에 올립니다(예: `001a.jpg`, `001b.jpg`). 두 그림은 크기가 같아야 합니다.
2. `config.txt`의 `[틀린그림 사용자 이미지]` 아래에 한 줄씩 적습니다.
   ```
   001a.jpg | 001b.jpg | 23,40,5; 70,22,4; 51,80,6
   ```
   위치는 **그림 왼쪽 위 기준 퍼센트**로 적습니다(가로%, 세로%, 반지름%). 차이는 `;`로 구분합니다.
3. 적어 둔 그림이 먼저 순서대로 나오고, 다 쓰면 자동 생성 그림이 이어집니다.

## 5. 앱(APK)으로 만들기 — PWABuilder

1. https://www.pwabuilder.com 에 `https://swxd456-spec.github.io/-/quest/` 를 넣고 **Start**를 누릅니다.
2. **Package for stores → Android → Google Play**를 고릅니다.
   - Package ID 예: `io.github.swxd456spec.palace`
   - 결제를 쓰려면 *Enable Play Billing*을 체크합니다.
3. 받은 zip 안의 `.aab`는 Play Console에 올리고, `.apk`는 휴대폰 테스트용입니다. `signing.keystore`와 `signing-key-info.txt`는 **꼭 따로 보관**하세요. 잃어버리면 앱을 업데이트할 수 없습니다.
4. 주소창 없이 전체화면으로 열리게 하려면 zip 안의 `assetlinks.json`을 `https://swxd456-spec.github.io/.well-known/assetlinks.json` 에 올려야 합니다. 이 파일은 **`swxd456-spec.github.io` 라는 이름의 저장소**에 넣어야 합니다. 프로젝트 저장소(`-`)에 넣으면 인식되지 않습니다.

## 6. 정책 주의

- 구매 가능한 코인으로 슬롯을 돌리는 앱은 Google Play의 **시뮬레이션 도박(소셜 카지노)** 정책을 적용받습니다. 연령 등급 설문에 이 내용을 정확히 답하고, 현금화나 경품 교환은 절대 넣지 마세요.
- 한국에서는 게임물관리위원회 등급 분류가 필요할 수 있습니다. 출시 전에 확인하세요.
- 지갑이 기기에 저장되므로(localStorage) 실서비스에서는 서버 저장으로 바꾸는 것을 권장합니다.
